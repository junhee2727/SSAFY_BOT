# 설정 및 실행

## 목적

개인 PC에서 봇을 설치·설정·실행하고 각 연동 기능을 독립적으로 유지한다.

기준 문서: [전체 구현 계획](../plan.md)

## 실행 구성과 기본값

- TypeScript/Node.js 단일 프로세스와 로컬 SQLite를 사용한다.
- 개인 사용자 1명만 지원한다.
- 시간대는 `Asia/Seoul`로 설정한다.
- PC가 켜져 있고 프로세스가 실행 중일 때 동작한다.
- 수집·요약·전달 모듈을 분리해 이후 정보 제공 기능을 추가할 수 있게 한다.

## 설정 항목

| 구분 | 내용 |
| --- | --- |
| Mattermost | HTTPS 서버 주소, 본인 로그인 아이디·비밀번호, 필요 시 추가 인증 코드 |
| 네이버 메일 | IMAP 인증정보, 대상 메일함, 발신자 허용 목록 |
| GMS | API 키, 모델명, 엔드포인트 |
| 예약 작업 | 뉴스레터 발송 시간: 기본 오전 9시 |

- 비밀값은 `.env`에서 관리한다.
- 발신자 목록과 예약 시간은 설정 파일로 분리한다.
- `.env.example`, 로컬 DB와 비밀값의 Git 제외 규칙, 설치·실행 안내를 제공한다.
- 시작 시 필수 설정을 검사한다.
- `config:check`는 설정 형식만 확인하고, `mattermost:check`는 로그인과 ‘나와의 대화’ 조회/생성을 확인한 뒤 검사 세션을 로그아웃한다. 메시지는 발송하지 않는다.
- 사용자 ID는 로그인 응답에서 가져오며 아이디·비밀번호 인증만 지원한다.
- 메일 또는 GMS 장애가 발생해도 할 일 기능은 유지한다.

## 연동 전제

- Mattermost에서 본인 아이디·비밀번호 로그인이 가능해야 한다. 서버가 추가 인증을 요구하면 현재 코드를 사용한다.
- PC에서 Mattermost REST API와 WebSocket에 접속할 수 있어야 한다.
- 네이버 메일 IMAP을 활성화하고 필요한 인증정보를 설정한다.
- 실제 Mattermost 아이디·비밀번호, 메일 인증정보, GMS 키, 뉴스레터 발신자 주소는 사용자가 PC에 설정한다.

## 검증과 완료 기준

- 외부 서비스 모의 응답으로 기능별 자동 검증을 수행한다.
- 타입 검사와 빌드를 통과시킨다.
- 누락된 필수 설정을 시작 시 감지한다.
- 메일·GMS 장애가 할 일 기능을 중단시키지 않는다.
- 실제 계정으로 할 일 등록 → 목록 조회 → 완료와 테스트 뉴스레터 수집 → 요약 → DM 전달을 확인한다.

## 후속 범위

- 상시 서버 배포.
- 자연어 할 일 해석.
- 날씨·공지 등 기타 정보 연동.
- 첫 버전에는 공개 HTTP API와 관리 웹 화면을 만들지 않는다.
