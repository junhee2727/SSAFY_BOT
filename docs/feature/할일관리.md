# 할 일 관리

## 목적

Mattermost DM으로 개인 할 일을 등록·조회·완료·삭제한다.

기준 문서: [전체 구현 계획](../plan.md)

## 명령 인터페이스

| 명령 예시 | 동작 |
| --- | --- |
| `할일 추가 보고서 제출 /마감 2026-09-21 18:00` | 마감이 있는 할 일 등록 |
| `할일 추가 알고리즘 공부` | 마감 없이 등록 |
| `할일 목록` | 미완료 할 일과 번호 표시 |
| `할일 완료 3` | 해당 번호 완료 처리 |
| `할일 삭제 3` | 해당 번호 삭제 |

## 동작과 요구사항

- 정해진 명령 문법으로 처리한다. 자연어 할 일 해석은 후속 범위다.
- 마감 시각은 한국 시간(`Asia/Seoul`)을 기준으로 해석한다.
- 잘못된 날짜나 번호에는 수정 방법을 안내한다.
- 할 일과 완료 상태를 SQLite에 저장해 재실행 후에도 유지한다.
- 메일 수집이나 GMS 장애가 발생해도 할 일 기능은 유지한다.

## 의존 기능

- [매터모스트 연동](매터모스트연동.md): 명령 수신과 응답.
- [데이터 저장 및 복구](데이터저장및복구.md): 할 일 상태 보존.
- [마감 알림](마감알림.md): 마감이 있는 미완료 할 일 알림.

## 검증 기준

- 마감 유무에 따라 할 일을 등록할 수 있다.
- 미완료 목록에서 번호를 확인하고 완료·삭제할 수 있다.
- 잘못된 명령·날짜·번호에 수정 안내를 제공한다.
- 재실행 후 데이터가 유지되고, 메일·GMS 장애 중에도 명령이 동작한다.
- 실제 Mattermost DM에서 등록 → 목록 조회 → 완료 흐름을 확인한다.
