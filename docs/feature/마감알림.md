# 마감 알림

## 목적

할 일의 마감 시각에 알림을 보내고, 실행 중단으로 놓친 알림을 복구한다.

기준 문서: [전체 구현 계획](../plan.md)

## 동작과 요구사항

- 한국 시간(`Asia/Seoul`) 기준으로 예약 작업을 실행한다.
- 마감 시각에 미완료 할 일을 한 번 알린다.
- 마감이 없는 항목과 이미 완료·삭제한 항목은 알림 대상에서 제외한다.
- PC가 꺼져 놓친 마감 알림은 재실행 시 묶어서 전달한다.
- 발송 대기·완료 기록을 보존해 재실행 후 같은 알림이 반복되지 않도록 한다.
- PC가 켜져 있고 프로세스가 실행 중일 때 예약 작업이 동작한다.

## 의존 기능

- [할 일 관리](할일관리.md): 마감 시각과 완료 상태 제공.
- [매터모스트 연동](매터모스트연동.md): DM 발송.
- [데이터 저장 및 복구](데이터저장및복구.md): 알림 상태 보존과 재시도.

## 검증 기준

- 미완료 할 일의 마감 시각에 알림을 보낸다.
- 완료·삭제한 항목과 마감이 없는 항목은 발송하지 않는다.
- 재실행 시 놓친 알림을 묶어서 전달한다.
- 이미 발송한 알림은 정상 재실행 후 반복하지 않는다.
