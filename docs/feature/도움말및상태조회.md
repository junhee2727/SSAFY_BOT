# 도움말 및 상태 조회

## 목적

사용자가 DM에서 명령 사용법과 봇의 처리 상태를 확인한다.

기준 문서: [전체 구현 계획](../plan.md)

## 명령 인터페이스

| 명령 | 응답 |
| --- | --- |
| `도움말` | 지원 명령과 사용 예시 |
| `상태` | 메일 수집·요약·예약 발송의 최근 성공과 오류 |

## 동작과 요구사항

- 도움말에 할 일 등록·목록·완료·삭제, 뉴스레터 조회, 상태 조회 명령을 안내한다.
- 마감이 있는 할 일과 없는 할 일의 입력 예시를 제공한다.
- 정해진 문법으로 명령을 처리하고, 잘못된 날짜나 번호에는 수정 방법을 안내한다.
- 상태 응답은 실제 수집·요약·예약 발송 기록을 기준으로 표시한다.

## 의존 기능

- [매터모스트 연동](매터모스트연동.md): 명령 수신과 응답.
- [할 일 관리](할일관리.md): 명령 문법과 예시.
- [데이터 저장 및 복구](데이터저장및복구.md): 처리 상태 확인에 필요한 기록.

## 검증 기준

- 도움말의 명령과 실제 지원 명령이 일치한다.
- 잘못된 명령·날짜·번호에 사용자가 수정할 수 있는 안내를 제공한다.
- 메일 수집·요약·발송 성공과 오류가 상태 응답에 반영된다.
