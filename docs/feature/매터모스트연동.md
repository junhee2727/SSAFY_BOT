# 매터모스트 연동

## 목적

허용된 개인 사용자와 봇 사이의 DM을 수신하고 응답한다.

기준 문서: [전체 구현 계획](../plan.md)

## 동작과 요구사항

- 봇 계정 토큰과 허용 사용자 ID를 설정한다.
- Mattermost WebSocket으로 메시지를 수신하고 REST API로 응답한다.
- 허용된 사용자의 봇 DM만 처리한다. 다른 사용자, 채널 메시지, 봇 자신의 메시지는 처리하지 않는다.
- 이미 처리한 메시지는 다시 실행하지 않는다.
- 연결이 끊기면 재접속하고 마지막 처리 지점 이후 DM을 조회한다.
- 수신한 명령을 할 일 관리, 뉴스레터 조회, 도움말 및 상태 조회 기능으로 전달한다.
- 발송 결과가 네트워크 오류로 불명확하면 최근 봇 게시물과 발송 식별자를 대조한 뒤 재시도해 중복을 줄인다.

## 전제와 의존 기능

- 관리자를 통해 봇 계정과 토큰을 확보한다.
- PC에서 Mattermost REST API와 WebSocket에 접속할 수 있어야 한다.
- 처리한 DM과 발송 기록은 [데이터 저장 및 복구](데이터저장및복구.md)를 사용한다.
- 인증정보는 [설정 및 실행](설정및실행.md)에서 관리한다.

## 검증 기준

- 허용 사용자의 DM에만 응답한다.
- 같은 DM을 재수신해도 명령을 중복 실행하지 않는다.
- 연결 복구 후 누락된 DM을 조회해 처리한다.
- 발송 재시도 시 기존 게시물과 발송 기록을 대조한다.
