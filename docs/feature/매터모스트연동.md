# 매터모스트 연동

## 목적

본인 계정의 ‘나와의 대화’ DM에서 명령을 수신하고 응답한다.

기준 문서: [전체 구현 계획](../plan.md)

## 동작과 요구사항

- 본인 로그인 아이디·비밀번호를 `.env`에 설정한다. 다른 인증 방식은 지원하지 않는다.
- `POST /api/v4/users/login` 응답에서 사용자 ID와 세션 토큰을 얻는다. 세션 토큰은 메모리에만 보관한다.
- 본인 사용자 ID로 `POST /api/v4/channels/direct`를 호출해 ‘나와의 대화’를 조회하거나 생성한다.
- Mattermost WebSocket으로 메시지를 수신하고 REST API로 응답한다.
- 로그인한 사용자가 ‘나와의 대화’ 채널에 입력한 메시지만 처리한다. 다른 사용자나 채널의 메시지는 처리하지 않는다.
- 프로그램 응답은 발송 ID나 게시물 속성으로 구분해 처리하지 않는다. 작성자 ID만으로 제외하면 본인의 명령도 누락되므로 사용하지 않는다.
- 이미 처리한 메시지는 다시 실행하지 않는다.
- 연결이 끊기면 재접속하고 마지막 처리 지점 이후 DM을 조회한다.
- 수신한 명령을 할 일 관리, 뉴스레터 조회, 도움말 및 상태 조회 기능으로 전달한다.
- 발송 결과가 네트워크 오류로 불명확하면 최근 봇 게시물과 발송 식별자를 대조한 뒤 재시도해 중복을 줄인다.

## 전제와 의존 기능

- 서버에서 본인 아이디·비밀번호 로그인을 사용할 수 있어야 한다. 필요 시 현재 추가 인증 코드를 설정한다.
- PC에서 Mattermost REST API와 WebSocket에 접속할 수 있어야 한다.
- 처리한 DM과 발송 기록은 [데이터 저장 및 복구](데이터저장및복구.md)를 사용한다.
- 인증정보는 [설정 및 실행](설정및실행.md)에서 관리한다.

## 검증 기준

- 아이디·비밀번호 로그인 후 사용자 ID로 자기 DM을 선택한다.
- 로그인 실패·시간 초과·잘못된 응답에서 비밀값을 출력하거나 인증 요청을 자동 반복하지 않는다.
- 연결 검사 후 생성한 로그인 세션을 로그아웃한다.
- 허용 사용자의 DM에만 응답한다.
- 같은 DM을 재수신해도 명령을 중복 실행하지 않는다.
- 연결 복구 후 누락된 DM을 조회해 처리한다.
- 발송 재시도 시 기존 게시물과 발송 기록을 대조한다.

## 현재 구현 상태

`npm run mattermost:check`로 로그인 → ‘나와의 대화’ 조회/생성 → 로그아웃을 확인할 수 있다. 실제 DM 명령 수신, 메시지 발송, 세션 만료 후 재연결은 후속 구현이다.
