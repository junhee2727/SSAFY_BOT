# 뉴스레터 수집

## 목적

네이버 메일에서 지정한 뉴스레터만 읽어 요약 가능한 텍스트와 링크를 준비한다.

기준 문서: [전체 구현 계획](../plan.md)

## 입력과 기본값

- 네이버 IMAP 인증정보.
- 설정 파일에 지정한 메일함과 발신자 허용 목록.
- 기본 메일함: `INBOX`.
- 수집 주기: 5분.
- 발신자를 등록하기 전에는 수집하지 않는다.

## 동작과 요구사항

- IMAP을 TLS로 연결한다.
- 최초 실행 이전 메일은 자동 수집하지 않고, 이후 수신한 대상 메일부터 처리한다.
- 메일 식별자를 저장해 동일한 메일을 중복 처리하지 않는다.
- 메일의 읽기 상태·폴더·내용을 변경하지 않는다.
- HTML 메일은 텍스트로 정리한다. 첨부파일과 원격 이미지는 가져오지 않는다.
- 제목·발신자·본문 텍스트·본문에서 추출한 원문 링크를 요약 단계에 전달한다.
- 수집 대상 뉴스레터 본문만 GMS 요약에 사용한다.
- 수집 오류가 발생해도 할 일 기능은 유지한다.

## 전제와 의존 기능

- 네이버 메일에서 IMAP을 활성화하고 필요한 인증정보를 설정한다.
- [설정 및 실행](설정및실행.md): 메일함·발신자·인증정보 설정.
- [데이터 저장 및 복구](데이터저장및복구.md): 수집 기준과 메일 식별자 보존.
- [뉴스레터 요약](뉴스레터요약.md): 수집한 본문의 후속 처리.

## 검증 기준

- 지정 메일함과 발신자에 해당하는 새 메일만 수집한다.
- 발신자 목록이 비어 있으면 수집하지 않는다.
- 최초 실행 전 메일과 이미 처리한 메일을 자동 재처리하지 않는다.
- HTML 및 한글 메일을 처리하고 원문 링크를 추출한다.
- 수집 전후 메일의 읽기 상태·폴더·내용이 유지된다.
