# 뉴스레터 전달

## 목적

뉴스레터 요약을 매일 예약 발송하고, DM 명령으로 최신 요약을 조회한다.

기준 문서: [전체 구현 계획](../plan.md)

## 인터페이스와 기본값

| 실행 계기 | 동작 |
| --- | --- |
| 매일 오전 9시 | 아직 발송하지 않은 요약을 묶어 DM으로 전달 |
| `뉴스레터` 명령 | 저장된 최신 뉴스레터 요약 조회 |
| 예약 시각 이후 재실행 | 놓친 발송 대상 항목을 묶어서 전달 |

- 시간대는 `Asia/Seoul`이며 예약 시간은 설정 파일에서 관리한다.

## 동작과 요구사항

- 메일별 제목·발신자·한국어 핵심 요약·추출한 원문 링크를 전달한다.
- 요약이 계속 실패한 메일은 제목·미리보기와 “요약 실패” 표시를 전달한다.
- 새 항목이 없으면 정기 메시지를 발송하지 않는다.
- 오전 9시에 PC가 꺼져 있었다면 재실행 후 누락된 항목을 한 번에 전달한다.
- 발송 대기·완료 상태를 저장해 재시작과 재시도에 활용한다.
- 결과가 불명확한 발송은 매터모스트 연동 기능의 게시물 대조 절차를 따른다.

## 의존 기능

- [뉴스레터 요약](뉴스레터요약.md): 요약 결과 또는 실패 안내 제공.
- [매터모스트 연동](매터모스트연동.md): 명령 수신과 DM 발송.
- [데이터 저장 및 복구](데이터저장및복구.md): 요약 조회와 발송 기록.
- [설정 및 실행](설정및실행.md): 예약 시간 설정.

## 검증 기준

- 한국 시간 오전 9시에 미발송 항목만 정기 발송한다.
- 새 항목이 없으면 정기 발송하지 않는다.
- 명령으로 저장된 최신 요약을 조회할 수 있다.
- 재실행 시 누락된 항목을 전달하고, 정상 발송된 항목은 반복 발송하지 않는다.
- 실제 테스트 뉴스레터 수집 → GMS 요약 → DM 전달 흐름을 확인한다.
