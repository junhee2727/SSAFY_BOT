# 뉴스레터 요약

## 목적

수집한 뉴스레터를 SSAFY GMS로 요약해 한국어 핵심 정보를 제공한다.

기준 문서: [전체 구현 계획](../plan.md)

## GMS 호출 인터페이스

사용자가 제공한 호출 예시를 기준으로 구현한다.

```text
POST https://gms.ssafy.io/gmsapi/generativelanguage.googleapis.com/v1beta/models/gemini-3.5-flash:generateContent
Content-Type: application/json
x-goog-api-key: <GMS_KEY>
```

```json
{
  "contents": [
    {
      "parts": [
        {
          "text": "요약 지시와 뉴스레터 본문"
        }
      ]
    }
  ]
}
```

- Node.js의 `fetch`를 사용한다.
- 기본 모델은 `gemini-3.5-flash`이며 모델명과 엔드포인트는 설정 가능하게 한다.

## 동작과 요구사항

- 메일별 한국어 핵심 요약을 3~5개 항목으로 생성한다.
- 제목·발신자·요약·메일 본문에서 추출한 원문 링크를 저장한다.
- 뉴스레터 본문을 요약 대상 데이터로 취급한다. 본문 안의 지시를 실행하거나 도구를 호출하지 않는다.
- 긴 본문은 나누어 요약한 후 합친다.
- 링크는 모델이 생성한 URL 대신 메일에서 추출한 URL을 사용한다.
- 완료한 요약은 재사용한다.
- 일시적 오류는 제한적으로 재시도한다.
- 계속 실패하면 제목·미리보기와 “요약 실패” 표시를 전달 단계에 제공한다.

## 의존 기능

- [데이터 저장 및 복구](데이터저장및복구.md): 요약 저장과 재사용.
- [뉴스레터 전달](뉴스레터전달.md): 요약 및 실패 안내 발송.

## 검증 기준

- 지정한 URL·인증 헤더·요청 본문 형식으로 호출한다.
- 일반 본문과 긴 본문을 한국어로 요약한다.
- 이미 완료한 요약은 불필요하게 다시 호출하지 않는다.
- GMS 오류·빈 응답·시간 초과 시 재시도와 실패 안내가 동작한다.
- 본문에 명령이 포함되어도 작업을 실행하지 않고, 원문에 없는 링크를 전달하지 않는다.
